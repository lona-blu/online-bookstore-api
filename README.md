# Online Bookstore API

A complete REST API for an online bookstore with user authentication, book management, and reviews.

## Features
- Get all books
- Search books by ISBN, author, or title
- User registration and login (JWT authentication)
- Add, modify, and delete book reviews
- Node.js client with async/await and Promise implementations

## Installation
1. Clone repository
2. Run `npm install`
3. Start server: `npm start`
4. Test with included Node.js client: `npm run client`
